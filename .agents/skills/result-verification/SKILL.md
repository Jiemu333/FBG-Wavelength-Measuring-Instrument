# 结果截图校验

1. 在 `D:\SRTP_Work\projects\` 中定位对应算例、运行目录及 `results/figures/` 截图。读取该工程的 README 和已有求解日志；不以截图文件名代替结果证据。
2. 逐张查看截图，核对对象或数据集、属性、偏压或波长范围、标量操作、坐标、单位、色标及与其他图的对应关系。用原生工程或日志能够读取的数值交叉检查；无法独立验证的项目标为“待核验”。不生成截图或自制结果图。
3. 在截图所在文件夹写 `README.md`，用表格列出每张图片、对应工程与结果入口、核验依据、结论和适用范围；区分仿真数据与实测数据。原有工程 README 只在工程本身发生变化时修改。
4. 只将核验通过且适合分享的截图和报告加入 Git，排除 `desktop.ini` 等无关文件。按用户对该仓库已有的上传授权提交并推送；若远端或上传权限不明确，先停在可审查的提交清单。推送后核对远端提交号。
